🌑 DARKMESH

Fork di Meshtastic focalizzato su messaggi programmati, affidabilità e inoltro metadata.

Android - Funzionalità

  • Hunting Mode: imposta un channel primario senza encryption per agevolare ricerca e messaggi broadcast verso pubblico generico
  • Messaggi Programmati: pianifica invio messaggi con data/ora
  • Beaconing: genera automaticamente messaggi beacon per tracciamento nodi
  • Gateway Detection: rileva nodi gateway nella rete
  • Messaggi in Coda: gestisce messaggi pendenti e retry automatici
  • Compressione Messaggi: riduce dimensione pacchetti per maggiore efficienza
  • Database Nodi: salva e gestisce informazioni sui nodi rilevati
  • Statistiche Avanzate: analisi dettagliate traffico e prestazioni
  • UI Migliorata: interfaccia ottimizzata per uso su campo

Firmware - Patches

  • Sleep Recovery: migliora la sincronizzazione dopo sleep mode
  • Auto Zero Cost Hop: ottimizza routing evitando hop inutili
  • Console Module: modulo debug avanzato
  • Metadata Forwarding: inoltro informazioni metadata tra nodi
  • Fixed Position Override: permette override posizione fissa da client
