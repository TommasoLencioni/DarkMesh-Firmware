# DarkMesh Firmware Download Site

Static website for downloading DarkMesh firmware builds.

## Features

- Browse all firmware releases
- Select device model (Heltec V3, WSL V3, RAK4631)
- Download firmware files directly
- Automatically updated via GitHub Releases API

## Local Development

Simply open `index.html` in your browser. No build process needed.

## Deployment

This site is deployed via GitHub Pages from the `/docs` folder.
