📻 Radio LoRa 📻

Hardware testato per DarkMesh

Heltec WiFi LoRa 32 V3

Specifiche: ESP32-S3R2, chipset SX1262, 22dBm output power

Caratteristiche

  • WiFi integrato per configurazione remota
  • Display OLED integrato
  • Ottimo rapporto qualità/prezzo
  • Basso consumo in idle (~30mA)
  • Picchi di trasmissione: ~120mA @ 22dBm

Consumo Energetico

  • Trasmissione (22dBm): 120-140mA
  • Ricezione: 40-50mA
  • Idle: 25-35mA
  • Deep Sleep: < 1mA

🔗 Sito Produttore

LilyGo T-BEAM 1 Watt

Specifiche: ESP32, SX1262 + amplificatore esterno, fino a 30dBm (1W)

Caratteristiche

  • GPS integrato
  • Amplificatore RF esterno (fino a 30dBm)
  • Batteria 18650 integrata
  • Ideale per installazioni fisse come gateway
  • Richiede antenna adeguata per gestire 1W

Sezione RF

Include amplificatore di potenza esterno che porta l'output fino a 30dBm (1 Watt). ⚠️ Attenzione: richiede antenna con capacità di gestione potenza adeguata e rispetto normative locali.

Consumo Energetico

  • Trasmissione (30dBm / 1W): 800-1000mA
  • Trasmissione (22dBm): 120-150mA
  • Ricezione: 50-60mA
  • Idle: 40-50mA
⚠️ Peak Power vs Average Power
La potenza di picco (1W) si riferisce al massimo istantaneo durante trasmissione. La potenza media è significativamente inferiore e dipende dal duty cycle.

🔗 Sito LilyGo

💡 Raccomandazioni

  • Uso mobile: Heltec V3 (compatto, efficiente)
  • Gateway fisso: T-BEAM 1W (maggiore copertura)
  • Budget limitato: Heltec V3 (miglior rapporto qualità/prezzo)
  • Massima portata: T-BEAM 1W + antenna esterna di qualità
